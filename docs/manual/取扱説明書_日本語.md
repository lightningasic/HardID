# HardID ハードウェアウォレット 取扱説明書（日本語）

> バージョン v1.2 · 2026-08-15 · 対象ハードウェア：ESP32-S3 開発ボード（240×320 タッチパネル、物理ボタンなし）

---

## 1. 安全上の注意（最初にお読みください）

**最重要の警告：**

> ⚠️ **シードワード（ニーモニック）は、このウォレットで生成し、このウォレットにだけ入力してください。**
> **それ以外の場所でシードワードの入力を求められたら、それはすべて詐欺です（Webサイト、メール、アプリを含む）。**
> **「サポート」「公式」「復旧担当」を名乗る者を含め、誰にもシードワードを渡さないでください。**

3つの鉄則：

1. **秘密鍵はデバイスから出ません。** シードワードは画面上に一度だけ表示され、手書きで控えるためのものです。書き出し・ネットワーク接続は一切ありません。
2. **シードワードが唯一のバックアップです。** 手に入れた者は資産を奪えます。オフラインで、秘密に、手書きで保管してください。
3. **PINは「他人がデバイスを使えないようにする」ためのもので、シードワードではありません。** PINを忘れてもシードワードで復旧できます。シードワードの漏洩は復旧不能です。

**偽造品への注意：** 新品のデバイスはメニューを表示し、初期化を促します。PINやシードワードがすでに設定された状態で届いた場合は、他人が使用した可能性があります。使用せず、工場出荷状態に戻して再初期化してください。

## 2. 概要とメインメニュー

- 240×320 静電容量式タッチパネル、全タッチ操作、物理ボタンなし。USB Type-C 給電。
- 電源投入後ロゴが表示され、メインメニューへ。**左右の矢印で選択枠を移動し、OKまたは枠をタップして入ります。**

メインメニュー（全10項目。初期化後は INITIALIZE / RECOVER は非表示）：

| メニュー | 説明 |
|---|---|
| INITIALIZE | 新しいウォレットを生成（初回必須） |
| RECOVER | シードワードを入力して復元 |
| SIGN | ロック解除して署名 |
| HOST LINK | パソコンの署名要求に対応 |
| FIDO | FIDO パスキーサービスに入る（インストール時） |
| APP MARKET | 通貨アプリと FIDO のインストール／管理 |
| PIN | PIN の設定・変更と自動ロック時間 |
| ABOUT | バージョン情報 |
| LANGUAGE | 表示言語の切り替え（英/中/日/韓） |
| FACTORY RESET | 全データ消去 |

## 3. ウォレットの初期化

1. メニューで **INITIALIZE** を選択。
2. 最初に**シードワードの安全警告**が表示されます。読んで **I UNDERSTAND（理解しました）** をタップ。
3. リカバリーフレーズが一語ずつ表示されます。**すべて手書きで控えてください。** Next で次の単語へ。
4. **再確認**としてフレーズを一語ずつ再入力。一致しないと先へ進みません。
5. **PINを設定するか**尋ねられます（任意）。Yes → 4～16桁の数字PINを2回入力。No → PINなしで運用。
6. 完了してメニューへ戻ります。

---

## 4. ウォレットの復元（RECOVER）

1. 空のデバイスで **RECOVER** を選択。
2. **シードワードの安全警告**が表示されたら I UNDERSTAND をタップ。
3. 画面上のキーボードで一語ずつ入力。**1～4文字で一意になると単語が自動補完**されます。OKで確定、Backで削除。
4. チェックサムを検証。誤りは拒否され、既存状態を上書きしません。
5. PINを設定（任意）し、シードを保存。

---

## 5. 署名（SIGN）

- 署名にはPINのロック解除が必要です（FIDOは例外）。正しいPINでセッションが解除されます。
- トランザクションの内容（宛先・金額・リスク）が画面に表示されます。**画面で確認した内容がそのまま署名されます。** Confirmで署名、Cancelで中止。
- アイドル時間が自動ロック時間を超えると再ロックされ、再度PINが求められます。

---

## 6. FIDO（削除可能なプリインストールアプリ）

- FIDOは**削除可能なプリインストールアプリ**です。出荷時は**未インストール**。APP MARKET の **Available** ページで有効化すると、次回起動から FIDO パスキーサービス（セキュリティキー相当）に入ります。
- **FIDOはPIN不要**：サイトのログイン／登録の承認＝デバイスで「Yes」を押すこと。ウォレットPINは不要です。
- FIDOを削除すると（Installed → FIDO → DELETE）、**登録済みサイトの認証情報をすべて消去**し、ウォレット起動に戻ります。
- GitHub などでのパスキー登録・ログインに対応（FIDO2/WebAuthn）。

---

## 7. PIN（任意 + 自動ロック）

- PINは任意です。初回起動／初期化／復元／工場出荷時リセット後に設定を尋ねられ、スキップできます。
- **ウォレットに入るにはPINが必要**。解除後、**アイドル時に自動ロック**します。
- 自動ロック時間は **PIN → AUTO** で切替：30秒 / 1分 / 5分 / 10分 / 無効（デフォルト5分）。
- PINの変更には旧PINが必要。設定・変更すると即ロックされ、再入力が必要です。

---

## 8. APP MARKET

- **Installed App（インストール済み）**と**Available App（インストール可能）**の2ページ。
- Installed は通貨アプリ（BTC/ETH + カタログ LTC/DOGE/BCH/ETC/POLYGON など）と FIDO（インストール時）。
- Available はインストール可能な通貨アプリと FIDO（未インストール時）。

---

## 9. 言語切替（LANGUAGE）

- **LANGUAGE** を選び、`<` / `>` で **English / 中文 / 日本語 / 한국어** を選択、OKで確定。
- メニューは即座に選択した言語で再表示され、設定は保存されます。

---

## 10. 工場出荷時リセット（FACTORY RESET）

**危険：シード・PIN・FIDO認証情報を消去。復元できません。**

1. **FACTORY RESET** を選択。
2. 画面上のキーボードで **RESET を2回**入力して確認。
3. PIN設定済みならPINで所有権を確認。
4. 消去後、新しいPINを設定するか尋ねられ、工場出荷状態（FIDO未インストール）に戻ります。

---

## 11. よくある質問（FAQ）

- **PINを忘れた？** シードワードでデバイスを復元し、新しいPINを設定します（先に工場出荷時リセット）。
- **ネットワークに接続しますか？** いいえ。秘密鍵はデバイスから出ません。
- **FIDOにPINは必要？** いいえ。FIDOの承認はデバイス上での Yes です。
- **シードワードをサポートに送っていい？** 絶対にダメです。求められたらすべて詐欺です。
