> **2026-08-10 更新（S3 已验证 ✅）**：测试板（/dev/ttyACM0, USB-Serial-JTAG）首次烧录成功，启动日志干净：`hardid.main` → `board hw init` → `ST7789 init OK (240x320)` → `touch ready` → `starting UI task`，无崩溃无门禁挂起。
>
> **无 TTY 环境的日志捕获法**（idf_monitor 要求 TTY）：python fcntl/ioctl 单进程持有端口，TIOCMBIC(DTR) → TIOCMBIS(RTS) 拉低 EN 200ms → TIOCMBIC(RTS) 释放，select 读 15s。注意 `cat` 直读只能捡到复位瞬间一行，esptool `--after hard_reset` 的复位会丢后续输出。
>
> **走查中已修的真机问题**：
> 1. **RGB565 字节序**（`9f0015d`）：ST7789 默认大端色数据，整个 UI 此前字节对调运行 —— LOGO 亮蓝渲染成橄榄绿才暴露。修复 `.data_endian = LCD_RGB_DATA_ENDIAN_LITTLE` 后全 UI 颜色回归设计值
> 2. **LOGO 盲写**（`a218ecb`）：旧 logo.h 系 DeepSeek 无图像能力盲写，已由 `logo/gen_logo.py` 从 PNG 真图重新生成
> 3. **mock SE 无持久化**（`1ab26f4`）：RAM-only 导致重启即"空白设备"，brain phrase gate 永不触发 —— mock 加 NVS 持久化（种子+PIN；brain phrase 仍不持久化）
> 4. **按钮颜色**（`afaa8ba`）：字节序修正后 C_BTN 真值偏青绿，改品牌蓝 0x039E
> 5. **菜单误触**（`67c176a`/`9b17fa4`）：原"点任意区域即选中"，走查中频繁误触；改选框高亮 + 仅 OK/选框激活。选框初版 212px 装不下 FACTORY RESET（2x 下 232px），改通栏
> 6. **HOST LINK 挂屏提示 + 误退**（`67c176a`）：原提示行常驻且"点任意处退出"，stray 触摸误退会话；改显式 BACK 按钮，仅 BACK 可退出
> 7. **彩色窄条**（`60c1e3d`）：菜单选框/右下导航键出现水平彩色杂条 —— esp_lcd SPI 颜色传输零拷贝+异步队列，绘制函数返回后栈行缓冲被触摸轮询复用，DMA 读到垃圾。修复：每个绘制函数返回前发 MIPI NOP（0x00）排空在途事务
>
> **HOST LINK 结构化 SIGN 走查**（`f40a653`，板回线后执行）：
> - 菜单 → HOST LINK → PIN 解锁（dev 构建自动解锁）→ 显示 "Host link serving"
> - 主机发一帧 `HD_CMD_SIGN`（app_id="eth" + path m/44'/60'/0' + 一笔 raw EVM tx，见 `tests/test_linksvc.c` 载荷构造）
> - 设备屏应显示**解析后的交易意图**（to/amount/手续费/chain id，即 WYSIWYS 确认屏，不再是 hex digest）→ 屏上确认
> - 设备返回 OK 帧：`sig_count(4 BE) | [ sig64(64) | recid(1) ] × sig_count`，
>   `HD_REPLY_OK`（EVM 单签 sig_count=1；BTC 逐输入签名，主机侧用 `core/tx_asm.c`
>   组装 v/r/s 或 DER+witness）

**若 `SE init FAILED`**：
- 检查 SPI 接线（CS1=GPIO10, CS2=GPIO9, SCLK/MOSI/MISO）
- 检查 ACL16 供电与复位（RESET=GPIO8，低有效）
- 用逻辑分析仪抓 SPI 波形确认时序

**若 `RNG self-test FAILED`**：
- ESP32-P4 TRNG 未使能 → 检查 `bootloader_random_enable()` 或 RNG 时钟
- **设计预期**：失败必须停机显示错误（这是安全特性，不是 bug）
