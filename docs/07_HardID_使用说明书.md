## 1. 安全须知

**在开始之前，请务必理解这三件最重要的事：**

- **你的加密资产永远不离开这台设备。** 私钥只在设备内生成、存储和用于签名，从不发送到电脑或网络。本设备永远不需要联网。
- **你的恢复短语是你资产的唯一备份。** 丢失设备、没电、损坏时，只有短语能重新生成钱包。**得到短语的人就能取走你的资产**，所以它必须离线、保密、亲手抄写。
- **PIN 保护的是「别人不能用你的设备」。** PIN 不等于恢复短语。忘记 PIN 可以用短语恢复；但短语泄露则资产无救。

**防伪造提示（与 Ledger/Trezor 一致）：**
- 全新设备首次开机，应显示主菜单，要求你主动「初始化」。
- 若设备收到时**已经预置了 PIN 或助记词**，说明可能被他人使用过，**不要使用**，应恢复出厂并重新初始化。

## 2. 设备概览与首次使用

| 项目 | 说明 |
|---|---|
| 屏幕与输入 | 240×320 电容触摸屏，全触控，**无物理按键** |
| 主菜单 | 开机直接进入主菜单 |
| 电源 | USB Type-C 供电（可边充边用） |

### 首次开机 → 进入主菜单

通电后屏幕先显示产品 LOGO，随后进入**主菜单**（左右箭头移动选框，点 **OK** 键或轻点选框进入；点其他区域无效）：

```
HardID
[INITIALIZE]  [SIGN]  [RECOVER]  [HOST LINK]
[FACTORY RESET]  [ABOUT]  [APP MARKET]
```

- 主菜单共 7 项功能：当前选中的功能包在一个高亮选框里，**左右箭头移动选框，点 OK 键或轻点选框进入**，**无需任何物理按钮**。
- **菜单随设备状态变化**：设备已初始化后，INITIALIZE / RECOVER 两项自动隐藏（它们只对空白设备有意义）；恢复出厂设置后重新出现。

> 功能一览：
> 1. **初始化**（Initialize）—— 生成新钱包：首次使用必做。
> 2. **签名**（Sign）—— 解锁并签名。
> 3. **恢复**（Recover）—— 通过屏上键盘输入你的恢复短语来重建钱包。
> 4. **主机链路**（Host link）—— 解锁后服务电脑的签名请求（开发/联调用）。
> 5. **恢复出厂**（Factory reset）—— 抹除设备全部数据。
> 6. **关于**（About）—— 版本信息。
> 7. **应用市场**（App market）—— 安装/管理币种 App（LTC、DOGE、BCH、ETC、POLYGON 等目录链）。

## 3. 初始化钱包（推荐第一步）

初始化是生成你的新钱包并设置 PIN 的过程。**只有真正的新设备 / 已恢复出厂后**才能初始化；若设备已初始化，本功能会提示「已初始化，需先恢复出厂」。

### 3.1 操作步骤（当前已实现）

1. 在**主菜单**轻触 **[1 Initialize]**。
2. 屏幕依次出现你的**恢复短语**（一组助记单词）。
   ```
   Recovery phrase
   abandon ability able ... cable   ← （示例，实际每台设备不同）
   [Cancel]               [Confirm]
   ```
3. **拿出纸笔，亲手抄写完整短语。** 抄写时保持按钮在屏幕上，确认无误后再轻触 **[Confirm]**。
   - 若不小心误点 **[Cancel]**，初始化会中止，重新进入后设备生成的是**全新的短语**。
4. 进入**设置 PIN** 页面，屏幕出现数字键盘：
   ```
   SET PIN（numeric）
   ****
   [1][2][3]
   [4][5][6]
   [7][8][9]
   [0] [ABC][DEL][OK]
   ```
5. 依次点按数字输入 **至少 4 位**的 PIN，点 **[OK]**。
6. 屏幕提示 **CONFIRM PIN**，**再次输入相同 PIN** 点 **[OK]**。
   - 两次不一致会提示 "PIN mismatch" 并让你重设。
   - PIN 太短（<4）会提示 "PIN too short"。
7. 完成后屏幕显示 **"Initialized OK. Seed + PIN stored."**。
8. **轻触任意位置**返回主菜单。

### 3.2 输入法说明（触摸屏专用）

- 键盘分页：**数字页**（PIN 专用）与**字符页**（A-Z / a-z / 0-9+符号 三页循环）：
  - 字符页切换键依次显示下一页：**[abc] → [1#$] → [ABC]**。
  - 输入 PIN 时只能用数字；输入 brain phrase 等可翻三页（大小写、数字、16 个常用符号 `!@#$%^&*()-_=+,.`、空格、DEL 退格、OK 确认）。
- **DEL**：删除最后一个字符；**OK**：确认。
- 触摸按键模型：按下按键后若手指仍在同一键内松开才生效，滑出则取消，防止误触；滑动经过字母时悬浮窗实时放大显示指尖下的字符。

### 3.3 PIN 的规范（安全建议）

- **至少 4 位数字**，建议 6–8 位。
- 不要用生日、顺序号（12345）等易猜数字。
- 连续输入错误多次后，建议按 Trezor 安全模型在硬件中自动抹除设备（当前 mock 固件为安全原型的占位实现，真实 SE 会强制）。

## 4. 签名交易

### 4.1 安全原则（Trezor / Ledger 一致）

签名**必须先在设备上解锁**：只有输对了 PIN，会话才会被解锁，否则设备拒绝签名（返回授权失败）。这条"设备解锁校验"是签名的**安全不变式**，当前固件已实现并真机验证。

即：**任何人，包括连接的电脑，都无法在你未输 PIN 的情况下让设备签名。**

### 4.2 当前已实现：设备端本地签名

> 说明：当前 mock 固件为验证触控与安全流程，签名的是**固定的测试摘要（digest）**，结果以 **r‖s 的十六进制**显示在屏上。此即设备内部自包含签名流程。

1. 在主菜单轻触 **[SIGN]**（已初始化设备可见）。
2. 开发期固件（无 PIN 模式）自动解锁；正式固件需先输 PIN 解锁会话。
   - PIN 错误 → 提示 "wrong PIN"，不签名，返回。
   - 设备未初始化 → 提示 "Not initialized"。
3. 确认屏显示**交易意图**：收款地址（按币种正确编码：BTC 显 `bc1…`、LTC 显 `ltc1…`）、金额、原生代币符号（LTC/ETC 等目录链显示自己的符号，不再显示 BTC）、手续费/风险等级。**确认屏所见 = 固件独立重解析交易原始字节的结果**，与 App 自报不一致会拒绝签名（WYSIWYS 双解析）。
4. 轻点 **Confirm** → 设备签名；**Cancel** → 放弃。
5. 签名结果显示：EVM 链显示一笔 r‖s；BTC 系按输入逐笔签名，屏上显示输入笔数与首笔签名。
6. 轻点返回主菜单。

> 本版起签名摘要是**真实链上 sighash**：EVM 按 EIP-155（自动注入/校验 chainId，拒绝已签名交易），BTC 系按 BIP143（仅支持原生 P2WPKH 输入 + SIGHASH_ALL）。已用 EIP-155 与 BIP143 官方测试向量校验。签名的最终组装（v/r/s、witness 注入）在主机侧完成。

### 4.3 规划：真实交易验证式签名（旗舰目标，规划中）

真实硬件钱包的签名是一个「**电脑 + 设备一同验证**」的过程，本说明书按这个旗舰目标记录，后续固件以此为标准实现：

1. 你在电脑软件（如钱包 App）中构造一笔交易。
2. 电脑把交易的**摘要（要签哪笔钱、发给谁、金额）**发送给设备。
3. **设备屏幕显示交易关键内容**（形式之一：收款地址 / 金额），**由你在屏上核对**。
4. 你输入 PIN（解锁）并在屏上点「确认」受签。
5. 设备运算签名并把签名返回电脑。电脑用它广播。

这个流程确保：**你的资产、交易内容的核验发生在设备安全的屏上**，而不是在你可能被病毒感染/别拦截的电脑上。

> 主机链路的**帧协议、校验、Clear-Sign 确认门与签名服务**已在固件中实现并可在本地测试（`tests/test_linkproto.c` / `test_linksvc.c`）。设备侧 `Host link` 画面接收**结构化 SIGN 请求**（App id + BIP32 派生路径 + 原始交易字节，PSBT/EVM），把交易意图解析并显示在屏上（与设备本机 SIGN 同一 WYSIWYS 确认屏）、需用户轻触确认后才签名，然后返回签名帧（EVM：一笔 r‖s；BTC：逐输入签名，主机侧组装 witness）。Host link 会话中点屏幕底部 **BACK** 按钮退出（点其他区域不会退出）。**USB-Serial-JTAG 端口与主机间的实际联调仍需真机完成。**（P1）

### 4.4 Brain Phrase（脑口令）

Brain phrase 是**助记词之上的第二层口令**，用于派生隐藏钱包（不同 brain phrase = 完全不同的钱包，互不可见）。

**安全规则（务必理解）：**
- **永不存储**：不写入设备任何存储，只在你脑中。设备掉电即忘。
- **每次开机输入**：已初始化的设备每次开机都会询问 "Enable brain phrase?"——选 Yes 并用字符键盘输入（三页翻页支持大小写/数字/符号），选 No 则使用基础钱包（空口令）。
- **只在本机键盘输入**：任何电脑、App、网站索要 brain phrase 都是骗局。
- **遗忘即永久丢失**：没有 brain phrase 无法派生对应钱包，连设备也无法帮你找回。
- **它不是独立脑钱包**：必须先有助记词备份，brain phrase 只是助记词之上的第二层；仅靠 brain phrase 本身无法恢复任何资产。

> 测试提示：开发板上空的测试钱包可以用 4 词测试种子 + 任意 brain phrase 快速体验该流程。

## 5. 恢复出厂设置

**危险操作**：抹除设备内全部数据（种子、PIN），不可恢复。

- 进入 **主菜单 → [3 Factory reset]**。
- 屏幕显示确认窗口，轻触 **[Confirm]** 确认，或 **[Cancel]** 取消。
  ```
  Wipe device? Seed + PIN will be erased.
  [Cancel]                    [Confirm]
  ```
- 确认后设备抹除，回到主菜单并显示已擦除提示。
- 之后需重新进行[第 3 节 初始化](#3-初始化钱包推荐第一步)才能使用。

> 安全警示：此操作只发生在**设备屏幕上的确认**中，电脑无法远程触发。执行前请确认你已安全备份并保存恢复短语。

## 6. 备份与恢复

### 6.1 备份你的恢复短语（离线）

- 恢复短语是**私钥的唯一备份**，必须在初始化时**亲手抄在纸上**。
- **切勿**拍照、**切勿**存进手机/电脑/云笔记，**切勿**发到任何软件或网站。
- 备份的纸存放在安全、干燥、私密处；避免与设备放在一处。

### 6.2 恢复

主菜单（空白设备）第 3 项 **RECOVER**：屏上键盘逐词输入短语 → 设备校验校验和并重建密钥 → 设置新 PIN 后存储。词错误（校验和不匹配）会被拒绝，不覆盖已有状态。

**词输入已优化**：从输入第一个字母起，键盘上方实时列出所有匹配的候选词（通常 2–3 个字母即可收窄到几个）；屏幕顶部恒显当前正在输入第几个词（WORD N）。每个 BIP39 词由前 4 个字母唯一确定，前缀无歧义时自动补全。

当前可用的重置路径：**恢复出厂**（第 5 节）后，可用 **RECOVER** 或 **INITIALIZE（新钱包）**。

> 测试提示：开发固件（`HARDID_DEV_TEST_SEED`）初始化时可选 **4 words (TEST)** 生成 4 词测试种子（44 位、无校验和，仅测试用），恢复时同样接受 4 词。正式固件不接受 4 词短语。

## 7. 常见问题（FAQ）

**Q1：忘记 PIN 怎么办？**
用你的恢复短语在（后续将支持的恢复功能，或新的初始化）恢复设备并设置**新 PIN**。PIN 独立于短语；你没有短语则无法找回资产。

**Q2：设备是否会联网？**
不会。设备离线工作，私钥永不离开硬件，也从不发送到主机或网络。

**Q3：主菜单没反应 / 屏幕闪烁？**
这可能是开发期（mock）固件的现象。已用「按下→触控需落在同一键内松开」的去抖模型 + 独立 UI 任务修复触控崩溃；若仍偶发，重启（RTS复位）即可重新进入。

**Q4：为什么签名结果是十六进制而不是「哈希确认」？**
当前 mock SE 固件签的是真实链上 sighash（EIP-155 / BIP143，已用官方测试向量校验），但签名本身由 mock SE 以确定性占位算法生成，**不是真实 ECDSA**；接入真实 SE 后即成为可广播的签名。mock 阶段验证的是「解析 → 双解析一致性 → 确认 → 签名」这条完整链路。

**Q5：恢复出厂后就空了吗？**
是。种子和 PIN 都会被擦除，设备回到未初始化状态，可重新初始化。（开发板上 mock SE 的种子/PIN 存在 MCU flash 的 NVS 区，恢复出厂一并擦除。）

**Q6：如何判断设备是否被改装（二手）？**
参考第 1 节：设备应处于**未初始化**状态（首次可初始化）。若首次开机就要求 PIN 或展示已存在助记词，请勿使用并恢复出厂。
