# HardID 하드웨어 지갑 사용 설명서（한국어）

> 버전 v1.2 · 2026-08-15 · 대상 하드웨어：ESP32-S3 개발 보드（240×320 터치스크린, 물리 버튼 없음）

---

## 1. 안전 주의사항（먼저 읽으세요）

**가장 중요한 경고：**

> ⚠️ **시드 단어는 이 지갑에서만 생성하고, 이 지갑에만 입력해야 합니다.**
> **웹사이트·이메일·앱 등 그 어떤 곳에서든 시드 단어를 요구하는 것은 모두 사기입니다.**
> **"고객지원" "공식" "복구 담당자"라고 하는 사람을 포함해 누구에게도 시드 단어를 알려주지 마세요.**

세 가지 원칙：

1. **개인키는 기기를 떠나지 않습니다.** 시드 단어는 화면에 한 번만 표시되며, 손으로 적기 위한 것입니다. 내보내기·네트워크 연결은 전혀 없습니다.
2. **시드 단어는 유일한 백업입니다.** 이를 가진 사람은 자산을 빼앗을 수 있습니다. 오프라인에서 비밀로 손으로 적어 보관하세요.
3. **PIN은 "다른 사람이 기기를 못 쓰게" 하는 것이지 시드 단어가 아닙니다.** PIN을 잊어도 시드 단어로 복구할 수 있지만, 시드 단어가 유출되면 복구 불가능합니다.

**위조 방지：** 새 기기는 메뉴를 표시하고 초기화를 안내합니다. PIN이나 시드 단어가 이미 설정된 상태로 도착하면 누군가 사용했을 수 있습니다. 사용하지 말고 공장 초기화 후 다시 초기화하세요.

---

## 2. 개요 및 메인 메뉴

- 240×320 정전식 터치스크린, 완전 터치, 물리 버튼 없음. USB Type-C 전원.
- 전원을 켜면 로고가 표시된 후 메인 메뉴로 진입합니다. **좌우 화살표로 선택 상자를 이동하고 OK 또는 상자를 눌러 들어갑니다.**

메인 메뉴（총 10개 항목. 초기화 후 INITIALIZE / RECOVER 는 숨김）：

| 메뉴 | 설명 |
|---|---|
| INITIALIZE | 새 지갑 생성（최초 사용 필수） |
| RECOVER | 시드 단어 입력으로 복구 |
| SIGN | 잠금 해제 후 서명 |
| HOST LINK | 컴퓨터의 서명 요청 처리 |
| FIDO | FIDO 패스키 서비스 진입（설치 시） |
| APP MARKET | 코인 앱 및 FIDO 설치/관리 |
| PIN | PIN 설정/변경 및 자동 잠금 시간 |
| ABOUT | 버전 정보 |
| LANGUAGE | 표시 언어 변경（영/중/일/한） |
| FACTORY RESET | 모든 데이터 삭제 |

---

## 3. 지갑 초기화

1. 메뉴에서 **INITIALIZE** 선택.
2. 먼저 **시드 단어 보안 경고**가 표시됩니다. 읽고 **I UNDERSTAND（이해함）** 를 누르세요.
3. 복구 문구가 한 단어씩 표시됩니다. **모든 단어를 손으로 적으세요.** Next 로 다음 단어로.
4. **재확인**으로 문구를 한 단어씩 다시 입력. 일치하지 않으면 진행되지 않습니다.
5. **PIN 설정 여부**를 묻습니다（선택）. 예 → 4~16자리 숫자 PIN을 두 번 입력. 아니요 → PIN 없이 사용.
6. 완료 후 메뉴로 돌아갑니다.

---

## 4. 지갑 복구（RECOVER）

1. 빈 기기에서 **RECOVER** 선택.
2. **시드 단어 보안 경고**가 표시되면 I UNDERSTAND 를 누르세요.
3. 화면 키보드로 한 단어씩 입력. **1~4자에서 유일해지면 단어가 자동 완성**됩니다. OK로 확정, Back으로 삭제.
4. 체크섬을 검증하며, 오류는 거부되고 기존 상태를 덮어쓰지 않습니다.
5. PIN을 설정（선택）하고 시드를 저장합니다.

---

## 5. 서명（SIGN）

- 서명 전에 PIN 잠금 해제가 필요합니다（FIDO는 예외）. 올바른 PIN으로 세션이 해제됩니다.
- 기기 화면에 거래 내용（수신자·금액·위험）이 표시됩니다. **화면에서 확인한 내용이 그대로 서명됩니다.** Confirm으로 서명, Cancel로 중단.
- 자동 잠금 시간을 초과하면 다시 잠기며 PIN을 다시 요구합니다.

---

## 6. FIDO（삭제 가능한 사전 설치 앱）

- FIDO는 **삭제 가능한 사전 설치 앱**입니다. 출하 시 **미설치** 상태. APP MARKET 의 **Available** 페이지에서 활성화하면 다음 부팅부터 FIDO 패스키 서비스（보안 키처럼）로 진입합니다.
- **FIDO는 PIN 불필요**：사이트 로그인/등록 승인 = 기기에서 **Yes** 를 누르는 것. 지갑 PIN이 필요 없습니다.
- FIDO 삭제 시（Installed → FIDO → DELETE）**등록된 사이트 인증 정보를 모두 삭제**하고 지갑 부팅으로 돌아갑니다.
- GitHub 등에서 패스키 등록·로그인 지원（FIDO2/WebAuthn）.

---

## 7. PIN（선택 + 자동 잠금）

- PIN은 선택 사항입니다. 최초 부팅/초기화/복구/공장 초기화 후 설정을 묻고 건너뛸 수 있습니다.
- **지갑 진입에는 PIN이 필요**하며, 해제 후 **유휴 시 자동 잠금**됩니다.
- 자동 잠금 시간은 **PIN → AUTO** 에서 전환：30초 / 1분 / 5분 / 10분 / 사용 안 함（기본 5분）.
- PIN 변경에는 기존 PIN이 필요. 설정·변경하면 즉시 잠기고 다시 입력해야 합니다.

---

## 8. APP MARKET

- **Installed App（설치됨）**과 **Available App（설치 가능）** 두 페이지로 나뉩니다.
- Installed 는 코인 앱（BTC/ETH + 카탈로그 LTC/DOGE/BCH/ETC/POLYGON 등）과 FIDO（설치 시）.
- Available 은 설치 가능한 코인 앱과 FIDO（미설치 시）.

---

## 9. 언어 변경（LANGUAGE）

- **LANGUAGE** 를 선택하고 `<` / `>` 로 **English / 中文 / 日本語 / 한국어** 를 골라 OK.
- 메뉴가 즉시 선택한 언어로 다시 표시되며, 설정은 저장됩니다.

---

## 10. 공장 초기화（FACTORY RESET）

**위험：시드·PIN·FIDO 인증 정보를 삭제. 되돌릴 수 없습니다.**

1. **FACTORY RESET** 선택.
2. 화면 키보드로 **RESET 을 두 번** 입력해 확인.
3. PIN이 설정되어 있으면 PIN으로 소유권을 확인.
4. 삭제 후 새 PIN 설정 여부를 묻고 공장 상태（FIDO 미설치）로 돌아갑니다.

---

## 11. 자주 묻는 질문（FAQ）

- **PIN을 잊었나요?** 시드 단어로 기기를 복구하고 새 PIN을 설정하세요（먼저 공장 초기화）.
- **네트워크에 연결되나요?** 아니요. 개인키는 기기를 떠나지 않습니다.
- **FIDO에 PIN이 필요한가요?** 아니요. FIDO 승인은 기기 위에서 Yes 를 누르는 것입니다.
- **시드 단어를 고객지원에 보내도 되나요?** 절대 안 됩니다. 요구하면 모두 사기입니다.
