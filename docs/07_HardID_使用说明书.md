## 1. 安全须知

**在开始之前，请务必理解这三件最重要的事：**

- **你的加密资产永远不离开这台设备。** 私钥只在设备内生成、存储和用于签名，从不发送到电脑或网络。本设备永远不需要联网。
- **你的恢复短语是你资产的唯一备份。** 丢失设备、没电、损坏时，只有短语能重新生成钱包。**得到短语的人就能取走你的资产**，所以它必须离线、保密、亲手抄写。
- **PIN 保护的是「别人不能用你的设备」。** PIN 不等于恢复短语。忘记 PIN 可以用短语恢复；但短语泄露则资产无救。

**防伪造提示（与 Ledger/Trezor 一致）：**
- 全新设备首次开机，应显示主菜单，要求你主动「初始化」。
- 若设备收到时**已经预置了 PIN 或助记词**，说明可能被他人使用过，**不要使用**，应恢复出厂并重新初始化。

## 2. 设备概览与首次使用

| 项目 | 说明 |
|---|---|
| 屏幕与输入 | 240×320 电容触摸屏，全触控，**无物理按键** |
| 主菜单 | 开机直接进入三选项主菜单 |
| 电源 | USB Type-C 供电（可边充边用） |

### 首次开机 → 进入主菜单

通电后屏幕先显示产品信息，随后进入**主菜单**：

```
HardID
tap an action
[1 Initialize]          
[2 Sign]               
[3 Factory reset]      
```

- 主菜单有三级功能，**用手指轻触**对应按钮即可。
- 每个子页面 / 弹窗都用触摸操作，**无需任何物理按钮**。

> 功能一览：
> 1. **初始化**（Initialize）—— 生成新钱包：首次使用必做。
> 2. **签名**（Sign）—— 解锁并签名。
> 3. **恢复出厂**（Factory reset）—— 抹除设备全部数据。

## 3. 初始化钱包（推荐第一步）

初始化是生成你的新钱包并设置 PIN 的过程。**只有真正的新设备 / 已恢复出厂后**才能初始化；若设备已初始化，本功能会提示「已初始化，需先恢复出厂」。

### 3.1 操作步骤（当前已实现）

1. 在**主菜单**轻触 **[1 Initialize]**。
2. 屏幕依次出现你的**恢复短语**（一组助记单词）。
   ```
   Recovery phrase
   abandon ability able ... cable   ← （示例，实际每台设备不同）
   [Cancel]               [Confirm]
   ```
3. **拿出纸笔，亲手抄写完整短语。** 抄写时保持按钮在屏幕上，确认无误后再轻触 **[Confirm]**。
   - 若不小心误点 **[Cancel]**，初始化会中止，重新进入后设备生成的是**全新的短语**。
4. 进入**设置 PIN** 页面，屏幕出现数字键盘：
   ```
   SET PIN（numeric）
   ****
   [1][2][3]
   [4][5][6]
   [7][8][9]
   [0] [ABC][DEL][OK]
   ```
5. 依次点按数字输入 **至少 4 位**的 PIN，点 **[OK]**。
6. 屏幕提示 **CONFIRM PIN**，**再次输入相同 PIN** 点 **[OK]**。
   - 两次不一致会提示 "PIN mismatch" 并让你重设。
   - PIN 太短（<4）会提示 "PIN too short"。
7. 完成后屏幕显示 **"Initialized OK. Seed + PIN stored."**。
8. **轻触任意位置**返回主菜单。

### 3.2 输入法说明（触摸屏专用）

- 键盘有**数字页**与**字母页**：
  - **[ABC] / [123]** 按钮在数字页与字母页之间切换。
  - 输入 PIN 时只能用数字；输入自定义短语等可切换字母页（A–Z、空格、DEL 退格、OK 确认）。
- **DEL**：删除最后一个字符；**OK**：确认。
- 触摸按键模型：按下按键后若手指仍在同一键内松开才生效，滑出则取消，防止误触。

### 3.3 PIN 的规范（安全建议）

- **至少 4 位数字**，建议 6–8 位。
- 不要用生日、顺序号（12345）等易猜数字。
- 连续输入错误多次后，建议按 Trezor 安全模型在硬件中自动抹除设备（当前 mock 固件为安全原型的占位实现，真实 SE 会强制）。

## 4. 签名交易

### 4.1 安全原则（Trezor / Ledger 一致）

签名**必须先在设备上解锁**：只有输对了 PIN，会话才会被解锁，否则设备拒绝签名（返回授权失败）。这条"设备解锁校验"是签名的**安全不变式**，当前固件已实现并真机验证。

即：**任何人，包括连接的电脑，都无法在你未输 PIN 的情况下让设备签名。**

### 4.2 当前已实现：设备端本地签名

> 说明：当前 mock 固件为验证触控与安全流程，签名的是**固定的测试摘要（digest）**，结果以 **r‖s 的十六进制**显示在屏上。此即设备内部自包含签名流程。

1. 在主菜单轻触 **[2 Sign]**。
2. 屏幕提示 **Unlock to sign**，要求输入。
3. 用屏上数字键盘输入你的 **PIN** 点 **[OK]**。
   - PIN 错误 → 提示 "wrong PIN"，不签名，返回。
   - 设备未初始化 → 提示 "Not initialized. Run Initialize first."
4. 解锁成功后，屏上显示签名结果：
   ```
   Signature (r||s)
   0xaa11bb22...         ← 64 字节 r‖s 十六进
   tap to return
   ```
5. **轻点任意位置**返回主菜单。

> 当前固件签名结果用于流程验证，**并非加密意义上可验证的真实 ECDSA**（真实 SE 后段才会落地）。这份说明书的读者请注意：mock 阶段用于验证「解锁 → 拒绝 — 解锁 → 签名成功」这条安全闸门。

### 4.3 规划：真实交易验证式签名（旗舰目标，规划中）

真实硬件钱包的签名是一个「**电脑 + 设备一同验证**」的过程，本说明书按这个旗舰目标记录，后续固件以此为标准实现：

1. 你在电脑软件（如钱包 App）中构造一笔交易。
2. 电脑把交易的**摘要（要签哪笔钱、发给谁、金额）**发送给设备。
3. **设备屏幕显示交易关键内容**（形式之一：收款地址 / 金额），**由你在屏上核对**。
4. 你输入 PIN（解锁）并在屏上点「确认」受签。
5. 设备运算签名并把签名返回电脑。电脑用它广播。

这个流程确保：**你的资产、交易内容的核验发生在设备安全的屏上**，而不是在你可能被病毒感染/别拦截的电脑上。

> 当前固件尚未实现电脑⇄设备通信（主机链路），因此第 2、5 步（主机链路）与第 3 步（设备屏幕显示真交易内容）为**规划中**。设备端 PIN 解锁与签名不变式（第 1、4 的一部分）已实现。

## 5. 恢复出厂设置

**危险操作**：抹除设备内全部数据（种子、PIN），不可恢复。

- 进入 **主菜单 → [3 Factory reset]**。
- 屏幕显示确认窗口，轻触 **[Confirm]** 确认，或 **[Cancel]** 取消。
  ```
  Wipe device? Seed + PIN will be erased.
  [Cancel]                    [Confirm]
  ```
- 确认后设备抹除，回到主菜单并显示已擦除提示。
- 之后需重新进行[第 3 节 初始化](#3-初始化钱包推荐第一步)才能使用。

> 安全警示：此操作只发生在**设备屏幕上的确认**中，电脑无法远程触发。执行前请确认你已安全备份并保存恢复短语。

## 6. 备份与恢复

### 6.1 备份你的恢复短语（离线）

- 恢复短语是**私钥的唯一备份**，必须在初始化时**亲手抄在纸上**。
- **切勿**拍照、**切勿**存进手机/电脑/云笔记，**切勿**发到任何软件或网站。
- 备份的纸存放在安全、干燥、私密处；避免与设备放在一处。

### 6.2 恢复（规划）

> Trezor / Ledger 模型提供了「在同一或另一台设备上输入短语以恢复钱包」的操作。本设备当前固件尚未提供**输入恢复短语**的入口；作为目标，恢复应支持：选择短语长度 → 逐词在屏上键盘输入（支持字母页）→ 设备重建密钥。

当前可用的重置路径：**恢复出厂**（第 5 节）后重新初始化。

## 7. 常见问题（FAQ）

**Q1：忘记 PIN 怎么办？**
用你的恢复短语在（后续将支持的恢复功能，或新的初始化）恢复设备并设置**新 PIN**。PIN 独立于短语；你没有短语则无法找回资产。

**Q2：设备是否会联网？**
不会。设备离线工作，私钥永不离开硬件，也从不发送到主机或网络。

**Q3：主菜单没反应 / 屏幕闪烁？**
这可能是开发期（mock）固件的现象。已用「按下→触控需落在同一键内松开」的去抖模型 + 独立 UI 任务修复触控崩溃；若仍偶发，重启（RTS复位）即可重新进入。

**Q4：为什么签名结果是十六进制而不是「哈希确认」？**
当前为**开发期 mock 固件**，签名固定测试摘要以验证触控 + PIN 安全门；后续接入真实 SE 后将签真实交易内容并按 4.3 节启用。

**Q5：恢复出厂后就空了吗？**
是。种子和 PIN 都会被擦除，设备回到未初始化状态，可重新初始化。

**Q6：如何判断设备是否被改装（二手）？**
参考第 1 节：设备应处于**未初始化**状态（首次可初始化）。若首次开机就要求 PIN 或展示已存在助记词，请勿使用并恢复出厂。
