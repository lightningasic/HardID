# HardID 硬件钱包使用说明书（中文）

> 版本 v1.2 · 2026-08-15 · 适用硬件：ESP32-S3 测试板（240×320 触摸屏，无物理按键）

---

## 1. 安全须知（先读这一段）

**最重要的告警：**

> ⚠️ **你的助记词（种子单词）只在钱包本机生成、也只应在钱包本机输入。**
> **任何其他要求你提供助记词的都是诈骗，包括但不限于：网页、邮件、APP。**
> **任何人（包括自称"客服""官方""修复人员"者）索取你的助记词，都不要给。**

三条铁律：

1. **私钥永不离开设备。** 助记词只在设备屏幕显示一次，用于你亲手抄写；绝不导出、绝不联网。
2. **助记词是你资产的唯一备份。** 丢了设备、没电、损坏，只有助记词能重建钱包；得到助记词的人就能取走你的资产。
3. **PIN 只保护"别人不能用你的设备"，不等于助记词。** 忘记 PIN 可用助记词恢复；助记词泄露则资产无救。

**防伪造提示：** 全新设备首次开机应显示主菜单并提示初始化。若设备到手时已预置 PIN 或助记词，说明可能被他人使用过，请勿使用，恢复出厂后重新初始化。

---

## 2. 设备概览与主菜单

- 240×320 电容触摸屏，全触控，无物理按键；USB Type-C 供电。
- 通电后显示 LOGO，随后进入主菜单。**左右箭头移动选框，点 OK 键或轻点选框进入。**

主菜单（共 10 项，顺序如下；已初始化后 INITIALIZE / RECOVER 自动隐藏）：

| 菜单项 | 说明 |
|---|---|
| INITIALIZE | 生成新钱包（首次使用必做） |
| RECOVER | 屏上键盘录入助记词恢复钱包 |
| SIGN | 解锁并签名 |
| HOST LINK | 服务电脑的签名请求 |
| FIDO | 进入 FIDO 通行密钥服务（已安装时显示） |
| APP MARKET | 安装/管理币种 App 与 FIDO |
| PIN | 设置/修改 PIN 与自动锁定时间 |
| ABOUT | 版本信息 |
| LANGUAGE | 切换界面语言（英/中/日/韩） |
| FACTORY RESET | 抹除设备全部数据 |

---

## 3. 初始化钱包

1. 主菜单选 **INITIALIZE**。
2. 首先出现**种子单词安全告警**，读完后点 **I UNDERSTAND（我理解）** 继续。
3. 屏幕逐词显示恢复短语（助记词），**拿出纸笔亲手抄写**，抄完点 Next 看下一个词。
4. 抄完后进入**二次确认**：按提示逐词重输短语，校验一致才生效（不一致不会继续，会要求重输）。
5. 询问**是否设置 PIN**（可选）：选 Yes 则设 4–16 位数字 PIN 并二次确认；选 No 则钱包无 PIN 运行。
6. 完成，返回主菜单。

---

## 4. 恢复钱包（RECOVER）

1. 主菜单（空白设备）选 **RECOVER**。
2. 先出现**种子单词安全告警**，点 I UNDERSTAND 继续。
3. 屏上键盘逐词输入助记词：**输入 1–4 个字母、前缀唯一时自动补全整个单词**（显示完整词）；按 OK 确认当前词，输错按 Back 退格。
4. 全部输完设备校验校验和，错误会被拒绝，不覆盖已有状态。
5. 询问是否设置 PIN（可选），完成后存储。

---

## 5. 签名（SIGN）

- 签名前须 PIN 解锁（FIDO 除外）。输入正确 PIN 解锁会话后才可签名。
- 设备屏逐字段显示交易意图（收款地址/金额/风险），**确认屏所见即所签**；点 Confirm 签名，Cancel 放弃。
- 空闲超过自动锁定时间会重新锁定，需再次输 PIN。

---

## 6. FIDO（可删除预装 APP）

- FIDO 是**可删除的预装 App**：出厂默认**未安装**；在 APP MARKET 的 **Available** 页激活后，下次开机直接进入 FIDO 通行密钥服务（类似 U 盾/安全密钥）。
- **FIDO 免 PIN**：登录/注册网站时的授权 = 在设备上点「Yes」确认，不需要钱包 PIN。
- 删除 FIDO：在 APP MARKET 的 Installed 页进入 FIDO → DELETE，会**清除所有已注册的网站凭证**并回到钱包开机。
- 已支持 GitHub 等网站的通行密钥注册与登录（FIDO2/WebAuthn）。

---

## 7. PIN（可选 + 自动锁定）

- PIN 可选：首次开机/初始化/恢复/恢复出厂后询问是否设置，可跳过。
- **进钱包需 PIN 解锁**；解锁后**空闲自动锁定**。
- 自动锁定时间可在 **PIN → AUTO** 循环设置：30s / 1min / 5min / 10min / 永不（默认 5min）。
- 修改 PIN 需先验证旧 PIN；设置或修改 PIN 后立即锁定，需重新输入。

---

## 8. 应用市场（APP MARKET）

- 分 **Installed App（已安装）** 与 **Available App（可安装）** 两页。
- 已安装页列出币种 App（BTC/ETH + 目录链 LTC/DOGE/BCH/ETC/POLYGON 等）与 FIDO（已安装时）。
- Available 页列出可安装的币种与 FIDO（未安装时）。

---

## 9. 语言切换（LANGUAGE）

- 主菜单选 **LANGUAGE**，`<` / `>` 选择 **English / 中文 / 日本語 / 한국어**，OK 确认。
- 选择后主菜单立即以所选语言显示；选择持久保存。

---

## 10. 恢复出厂（FACTORY RESET）

**危险操作：抹除种子、PIN 与 FIDO 凭证，不可恢复。**

1. 主菜单选 **FACTORY RESET**。
2. 屏幕键盘**输入两次 RESET** 确认。
3. 若设备已设 PIN，需验证 PIN 证明所有权。
4. 抹除后询问是否设置新 PIN，随后回到主菜单（回到出厂态：FIDO 未安装）。

---

## 11. 常见问题（FAQ）

- **忘记 PIN？** 用助记词恢复设备并设置新 PIN（需先恢复出厂）。
- **设备联网吗？** 不联网。私钥永不离开设备。
- **FIDO 需要 PIN 吗？** 不需要。FIDO 授权 = 设备上点 Yes。
- **助记词能发给客服吗？** 绝不能。任何人索取都是诈骗。
